# 저거뭐야 — 기획서 초안 (접수양식 작성용)

> 공모전 접수양식(기획서)에 옮겨 적기 위한 초안입니다. 숫자 중 **[가정]** 표시는 근거 자료로 교체하거나 그대로 가정임을 밝혀 쓰세요.

## 1. 한 줄 소개
운전하다 "방금 저거 뭐야?"라고 물으면, 차가 이미 지나친 것까지 기억해 음성으로 대답하고 "거기 가자" 한마디로 길 안내까지 이어 주는 창밖 가이드.

## 2. 문제 정의 (운전자·동승자 페인포인트)
- 차창 밖으로 궁금한 것(산, 건물, 다리, 처음 보는 명소)은 자주 지나가지만 **운전 중에는 검색할 수 없다.**
- 궁금해지는 순간 대부분 **이미 지나친 뒤**라 이름을 몰라 나중에도 찾기 어렵다.
- 아이가 "저거 뭐야?"라고 물어도 운전자는 대답할 방법이 없다.
- 기존 내비게이션은 "목적지까지 가는 길"만 알려줄 뿐, **지나가는 길 자체**에는 설명이 없다.

## 3. 핵심 기능과 사용 시나리오
| 상황 | 사용자 | 앱 |
|---|---|---|
| 올림픽대로 주행 중 | "방금 왼쪽에 지나간 거 뭐야?" | "방금 왼쪽에 지나친 곳은 세빛섬이에요. 반포대교 옆 한강 위에 떠 있는 인공섬이에요." |
| 이어서 | "거기 가자" | Pleos 내비게이션에 목적지 설정 (안내 중이면 경유지 추가) |
| 도심 진입 | (자동 해설 켬) | "400미터 앞 정면에 숭례문이 보여요." |
| 방향지시등 켜고 차선 변경 중 | — | 먼저 말 걸지 않음 (운전 부담 높은 순간 회피) |
| 목적지 도착 후 P단 | 화면 확인 | 오늘 물어본 곳 목록 → 설명 듣기 / 다음에 가 보기 |

## 4. 차량특화성 — 왜 차 안에서만 가능한가
1. **"방금 지나친 것"은 차의 궤적과 진행 방향이 있어야 계산된다.** 휴대폰은 "지금 여기"는 알지만 "1분 전 내 왼쪽"은 모른다. 차량 융합 위치(FusedLocation)의 연속 궤적과 헤딩으로 구간별 최근접점과 좌/우를 판정한다.
2. **운전 상황을 읽고 말하는 타이밍과 길이를 바꾼다.** 기어(P/D), 방향지시등, 차속(클러스터와 같은 PERF_VEHICLE_SPEED), 와이퍼, 전조등을 구독해 차선 변경 중엔 침묵하고, 고속 주행 중엔 한 문장만 말하고, 정차하면 상세 화면을 연다.
3. **주행 규제에 맞춘 음성 우선 설계.** CarUxRestrictions를 따라 주행 중에는 음성 + 큰 버튼 3개만 노출하고 긴 글·목록은 정차 시에만 보여준다(지역별 주행 규제 정책, 운전자 주의분산 가이드 준수).
4. **"거기 가자"가 차량 내비게이션과 바로 이어진다.** NaviHelper로 목적지/경유지를 설정해 궁금증 → 방문으로 연결된다.

## 5. 개발 계획 (구현 방식 · 개발 범위 · SDK/API 사용 계획)
**구현 방식**: Kotlin + Jetpack Compose, minSdk 28 / targetSdk 34, Pleos Connect Emulator v2.1.0에서 개발·검증. 판정 엔진·질의 해석은 안드로이드 의존 없는 순수 Kotlin으로 분리해 단위 테스트(15개) 적용.

**SDK/API 사용 계획 (모두 구현 완료)**
| SDK/API | 사용처 |
|---|---|
| FusedLocation `registerFusedLocationCallback` | 연속 궤적 수집 → 지나친 장소 판정 |
| FusedLocation `addProximityAlert` | 진행 방향 앞 명소 진입 시 자동 해설 트리거 |
| SpeechToText (ON_DEVICE / HYBRID) | 음성 질문 인식 |
| TextToSpeech (ON_DEVICE / HYBRID) | 답변 음성 출력 (차량 오디오·포커스 정책 연동) |
| NaviHelper `requestRoute` / `addWaypoint` / 이벤트 리스너 | "거기 가자" 목적지·경유지 설정, 안내 상태 확인 |
| Vehicle Gear / TurnSignal / Wiper / Light / Odometer | 주행·정차 전환, 운전 부담 인지, 야간·우천 멘트 |
| AAOS CarUxRestrictions, PERF_VEHICLE_SPEED | 주행 규제 UI 전환, 클러스터 동일 차속 |

**개발 범위와 일정**
| 시점 | 범위 |

| ~11/23 | 장소 데이터 확대: 한국관광공사 TourAPI 연동으로 전국 관광지 팩 |
| ~12/2 (PT 전) | 폼팩터(세로 1칸/가로 2칸) 테스트 보완, Playground 클라이언트 ID로 HYBRID 음성 전환, 시연 시나리오 리허설 |

## 6. 창의성
- 기존 서비스는 "목적지"나 "현재 위치 주변"을 다룬다. 저거뭐야는 **이미 지나친 과거 위치**를 질의 대상으로 삼는다.
- 화면을 보지 않고 **방향(왼쪽/오른쪽)과 시간(방금/아까)으로 가리키는** 차 안의 자연스러운 말투를 그대로 이해한다.
- 같은 질문에 후보가 여러 개면 "다른 거"로 다음 후보를 들려준다.

## 7. 사업성
**타깃**
- 1차: 주말 나들이·여행을 다니는 가족 운전자 (아이의 "저거 뭐야?")
- 2차: 출장·외근으로 낯선 지역을 자주 지나는 운전자, 국내 여행객(렌터카)

**예상 MAU 산정 방식** [가정 — 실제 보급 대수로 교체]
- Pleos Connect 탑재 차량 수 N × 앱 설치율 a × 월 1회 이상 주행 중 질문 비율 b
- 예: N = 10만 대, a = 15%, b = 60% → MAU ≈ 9,000 [가정]

**리텐션 근거**
- 주말 나들이·명절 귀성처럼 **반복되는 이동**마다 사용 계기가 생긴다.
- 자동 해설은 사용자가 따로 열지 않아도 주행 중 가치를 준다 (습관 형성).
- "오늘 지나온 곳" 기록이 쌓일수록 다시 가 볼 장소 목록으로 재방문 동기가 생긴다.

**수익 모델 (운전자에게 직접 과금하지 않는 구조 우선)**
1. 지자체·관광공사 B2G: 지역 명소 해설 팩 제작·노출 (관광 홍보 예산)
2. 휴게소·관광지·맛집 제휴: "거기 가자" 목적지 전환 성과형 제휴
3. 테마 해설 팩: 역사·드라마 촬영지·캠핑 등 프리미엄 콘텐츠

**확대 계획**
수도권 → 전국 TourAPI 팩 → 해외 지역(Pleos 차량 수출 지역) 현지어 TTS(en-US, es-MX, fr-CA 지원 로케일 활용) → 동승자용 상세 화면(뒷좌석 디스플레이)

## 8. 안전·개인정보
- 주행 중: 음성 우선, 큰 터치 타깃(88dp 이상), 고대비 다크 UI, 3줄 이내 텍스트, 자동 해설 최소 40초 간격, 방향지시등 작동 중 침묵
- 위치·차속은 기기 안에서만 계산하고 외부로 보내지 않음. 기록은 기기에 최근 100건만 저장, 정차 화면에서 삭제 가능
